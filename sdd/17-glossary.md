# 17. Glosario

| Término | Definición |
|---|---|
| Catálogo verificado | Productos y atributos confirmados por el propietario, con precio y vigencia trazables. |
| Mensaje aprobado | Texto que el usuario revisó y autorizó como referencia reutilizable. |
| Borrador | Propuesta editable que no se ha aprobado como plantilla ni enviado. |
| Contexto | Texto estrictamente seleccionado/revisado de forma manual para una sugerencia concreta. |
| Captura temporal | Imagen local creada por acción del usuario, disponible solo durante el flujo salvo decisión local explícita. |
| Knowledge base | Estrategias, FAQs y ejemplos anonimizados aprobados para recuperación por IA. |
| OpenCode | Servicio/proveedor al que pertenece la clave API del usuario; detalles técnicos pendientes. |
| Perfil Chrome | Perfil local independiente del navegador que puede abrir WhatsApp Web personal o Business. |
| Sync | Replicación autenticada de entidades estructuradas entre equipos del único propietario. |
| Tombstone | Marcador de borrado mantenido hasta que las réplicas confirman la eliminación. |
| Fallar cerrado | Bloquear la operación ante incertidumbre de autorización, privacidad, cuota o costo; mantener el dato local. |
| Dato local | Información guardada solo en el equipo, incluida ruta local de medios y secretos. |
| MV3 | Manifest V3, plataforma de extensiones de Chrome. |
| S/ 0 | Restricción de costo Cloudflare: no se acepta pago ni riesgo razonable de facturación. |
